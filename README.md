# e-Rice Smart System

A smart management platform for rice receipts, quality checks, farmer management, storage, and payment workflows.

## Features
- **Dashboard**: High-level metrics and operational overview
- **Farmer Management**: Track farmer registrations and profile data
- **Rice Receipt**: Receive and document paddy rice intake
- **Quality Check**: Moisture, purity, and grade evaluation
- **Storage Management**: Silo and warehouse allocation
- **Payment Management**: Calculate payouts and process transactions
- **Reports & Analytics**: Operational summaries and reporting
- **User Management**: Role-based access control and system users
